# BRYTER

> BRYTER is a no-code service automation and AI productivity platform for legal and professional-services teams. It exposes REST APIs (Execution, Database, Audit Log) and Custom Actions at developer.bryter.io, authenticated with a per-environment bearer API key against a tenant-specific host such as app.bryter.io.

This file was generated by the API Evangelist enrichment pipeline from BRYTER's public developer and product documentation. No provider-published llms.txt was found at developer.bryter.io/llms.txt (404).

## APIs

- [Execution API](https://developer.bryter.io/execution-api-reference): Trigger and execute BRYTER modules from external systems.
- [Database API](https://developer.bryter.io/database-api-reference): Read and synchronize BRYTER database data across platforms.
- [Audit Log API](https://developer.bryter.io/audit-log-api-reference): Retrieve tenant audit-log events.
- [Custom Actions](https://developer.bryter.io/custom-actions-reference): Extend BRYTER modules with custom nodes (npm @bryter_io/custom-actions).
